My First Web Page

Hello! This page is my first step into web development. It uses only HTML: a title, headings and paragraphs.

What is HTML?

HTML (HyperText Markup Language) describes the structure of a web page. Browsers read the tags and decide how to display each piece of content.

Why headings matter

Headings create an outline of the page. Screen readers and search engines use that outline to understand the content, so the levels should never be skipped.

Heading level 4

Used for a sub-point inside a level 3 section.
